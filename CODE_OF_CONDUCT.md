# Code of Conduct

This project adopts the **Contributor Covenant**, version 2.1, as its code of conduct. The canonical text is published at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

The Contributor Covenant 2.1 is the de facto standard code of conduct across the open-source ecosystem (used by Linux, Node.js, Rust, Kubernetes, and thousands of other projects). By contributing to this repository — through code, issues, pull requests, or discussions — you agree to abide by it.

## Scope

This code applies to all project spaces, including:

- GitHub repository (issues, pull requests, discussions, code review)
- Any official chat channels or community forums
- Project events and presentations where you officially represent Aprumo

It also applies when you represent the project in public, for example by using an official email address, posting from an official social media account, or acting as an appointed representative at an event.

## Enforcement

Instances of unacceptable behavior may be reported to the project maintainers at:

**security@aprumo.dev** _(placeholder — will be updated when the domain is registered)_

All reports will be reviewed and investigated promptly and fairly. The maintainers are committed to protecting the privacy and safety of anyone who reports an incident.

For the full list of unacceptable behavior categories, the enforcement guidelines, and the four-step consequence ladder (Correction → Warning → Temporary Ban → Permanent Ban), see the canonical Contributor Covenant 2.1 text linked above.
