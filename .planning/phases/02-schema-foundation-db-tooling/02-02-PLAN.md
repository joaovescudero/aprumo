CHECK: `status IN ('pending','reconciled','failed')`. Add `unique(['provider','provider_event_id'])` composite unique (FND-04).

    `accountBalance`: table name `account_balance`. `account_id` uuid PK FK→accounts.id, `balance` bigint({ mode: 'bigint' }) NOT NULL default 0n, `last_posting_id` uuid (nullable), `updated_at` timestamp withTimezone defaultNow NOT NULL.     `outboundEvents`: table name `outbound_events`. `id` uuid PK defaultRandom, `endpoint_id` uuid FK→outboundEndpoints.id NOT NULL, `type` text NOT NULL, `payload_jsonb` jsonb NOT NULL, `status` text NOT NULL default `'pending'`, `attempts` bigint({ mode: 'bigint' }) NOT NULL default 0n, `last_error` text, `next_attempt_at` timestamp withTimezone, `created_at` timestamp withTimezone defaultNow NOT NULL.
