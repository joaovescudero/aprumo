    Step 1 — Install packages into @aprumo/core:
    Run `pnpm --filter @aprumo/core add drizzle-orm postgres` (runtime deps).

    Step 2 — Create `packages/core/drizzle.config.ts`:
    Use `defineConfig` from `drizzle-kit`. Set `dialect: 'postgresql'`, `schema: './src/db/schema.ts'`, `out: './migrations'`. Leave `dbCredentials` absent (resolved at runtime from DATABASE_URL env var). Per D-36 and RESEARCH.md Pattern 1.

    Step 3 — Create `packages/core/src/db/migrate.ts`:
    ESM script. Import `drizzle` from `drizzle-orm/postgres-js`, `migrate` from `drizzle-orm/postgres-js/migrator`, `postgres` from `postgres`. Read `DATABASE_URL` from `process.env` — throw `Error('DATABASE_URL is required')` if absent. Connect with `{ max: 1 }` (CRITICAL: migrate() requires single connection per RESEARCH.md anti-patterns). Resolve `MIGRATIONS_FOLDER` using `fileURLToPath(import.meta.url)` + `resolve` to `../../migrations`. Call `await migrate(db, { migrationsFolder: MIGRATIONS_FOLDER })`. Wrap in try/finally to call `sql.end()`. Per RESEARCH.md Pattern 9.

    Step 4 — Create `packages/core/src/db/reset.ts`:
    ESM script. Read `DATABASE_URL` and `RESET_DB_NAME` (default `'aprumo'`) from env. Connect to the `postgres` system database. Run `DROP DATABASE IF EXISTS <dbname>` then `CREATE DATABASE <dbname>`. Warn to stdout: "DB reset complete — run pnpm db:migrate to reapply migrations." Only for dev (this script is intentionally destructive).

    Step 5 — Update `packages/core/package.json` scripts:
    Add: `"db:migrate": "tsx src/db/migrate.ts"`, `"db:reset": "tsx src/db/reset.ts"`, `"db:generate": "drizzle-kit generate"`, `"db:seed": "tsx migrations/0006_seed_dev.ts"`. Also update `files` array to `["dist", "migrations"]` per D-36.
    Add `tsx` as devDep: `pnpm --filter @aprumo/core add -D tsx`.

    Step 6 — Update root `package.json` scripts:
    Add: `"db:migrate": "pnpm --filter @aprumo/core db:migrate"`, `"db:reset": "pnpm --filter @aprumo/core db:reset"`, `"db:generate": "pnpm --filter @aprumo/core db:generate"`, `"db:seed": "pnpm --filter @aprumo/core db:seed"`. Per RESEARCH.md Pattern 9.

    Step 7 — Create `docker-compose.yml` at repo root:
    Use `postgres:18-alpine` image (per D-40 — same image as testcontainers). Service name `postgres`. Environment: `POSTGRES_USER: aprumo_migration`, `POSTGRES_PASSWORD: ${POSTGRES_PASSWORD:-changeme}`, `POSTGRES_DB: aprumo`. Port `5432:5432`. Volume `pgdata:/var/lib/postgresql/data`. Add `autovacuum_naptime=10` under command for pg-boss (FND-12). Named volume `pgdata`. Per D-17 (deferred from Phase 1) and FND-12.

    Step 8 — Create `.env.example`:

Never commit real passwords — gitleaks from Phase 1 will block it.
