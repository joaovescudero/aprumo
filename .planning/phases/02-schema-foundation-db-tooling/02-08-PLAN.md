## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| testcontainer→CI | Container must use pinned image for reproducibility |
| test schema→production schema | Schema-per-file prevents test pollution between files |
| inject('pgUri')→fork process | inject() is the only safe bridge; env var approach is alternative |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-2-01 | Tampering | postings mutation in tests | mitigate | REVOKE tests use aprumo_app pool (with proper role credentials) — not superuser pool |
| T-2-02 | Tampering | schema drift | accept (Plan 09) | globalSetup runs fresh migrations each test run; drift detected by Plan 09 CI gate |
| T-2-03 | Tampering | test isolation failure (schema collision) | mitigate | SHA1 hash of testPath produces unique schema name; migrationsSchema per test schema prevents _drizzle_migrations collision |
| T-2-04 | Spoofing | inject('pgUri') returns undefined | mitigate | inject() called inside createTestDb function body (never at module top-level); Pitfall 3 explicitly avoided |
| T-2-05 | Tampering | test container data leakage | mitigate | afterAll calls cleanup() which runs DROP SCHEMA CASCADE; schema-per-file with forks pool means no shared state |
| T-2-SC | Tampering | npm installs | transfer | Completed Plan 01 |
</threat_model>
