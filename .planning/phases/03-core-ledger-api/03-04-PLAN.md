<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP request body → Fastify route handler | coerceTypes:false + removeAdditional:all prevent type coercion attacks and mass assignment |
| JSON response → API consumer | setSerializerCompiler ensures BigInt never reaches native JSON.stringify (which throws) |
| Request logs → pino output | redact config prevents Idempotency-Key and auth headers from appearing in logs; bodies never logged (owner_ref, metadata never emitted) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04a | Tampering | Ajv coerceTypes | mitigate | coerceTypes: false in Fastify constructor; numeric idempotency_key cannot be silently coerced to string |
| T-03-04b | Tampering | Mass assignment | mitigate | removeAdditional: 'all' strips unknown fields from request bodies before handlers see them |
| T-03-04c | Tampering | Prototype pollution | mitigate | onProtoPoisoning: 'error' in Fastify constructor rejects __proto__ injection attempts |
| T-03-04d | Information Disclosure | pino request logs | mitigate | redact array covers authorization, cookie, and idempotency-key header values; request/response bodies never logged wholesale; owner_ref and metadata never emitted to log output |
| T-03-04e | Information Disclosure | OpenAPI spec at /docs | accept | /docs is unauthenticated (auth deferred per CONTEXT.md); spec contains no secrets, only schema documentation |
</threat_model>
