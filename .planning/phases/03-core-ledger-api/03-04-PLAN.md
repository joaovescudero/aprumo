<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP request body → Fastify Ajv | User-supplied JSON passes through Ajv validation before reaching handler |
| JSON response → HTTP client | BigInt values must be serialized as strings before JSON encoding |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04a | Tampering | Fastify Ajv coerceTypes | mitigate | `coerceTypes: false` enforced in Fastify constructor options; RESEARCH.md Pitfall 3 documents the money-corruption risk if omitted. Verified by: `grep -c "coerceTypes: false" packages/core/src/api/server.ts` |
| T-03-04b | Tampering | JSON prototype pollution | mitigate | `onProtoPoisoning: 'error'` in Fastify options; Fastify throws on `__proto__` key in request body |
| T-03-04c | Tampering | Mass assignment via extra body fields | mitigate | `removeAdditional: 'all'` in Ajv strips unknown properties before handler sees them |
| T-03-04d | Tampering | amount_cents as float in request body | mitigate | PostingInputSchema uses `Type.Integer({ minimum: 1 })` — Ajv rejects floats and negative values. TypeBox `Type.Integer` maps to JSON Schema `type: 'integer'` which Ajv strictly enforces |
| T-03-04e | Information Disclosure | BigInt raw in JSON response | mitigate | `registerBigIntSerializer` uses `setSerializerCompiler` with `typeof value === 'bigint' ? value.toString() : value` replacer; registered before routes so applies globally |
| T-03-04f | Denial of Service | Unbounded pagination limit | mitigate | PaginationQuerySchema.limit has maximum: 100 — values above 100 rejected with 422 by Ajv |
</threat_model>
