<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cursor query parameter → SQL WHERE clause | Cursor is user-supplied opaque string; decode failure must return 400 not 500 |
| limit query parameter → DB LIMIT | TypeBox maximum:200 enforced by Ajv before handler runs |
| POST body → accounts INSERT | owner_ref and metadata are user-supplied strings/JSON |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06a | Tampering | cursor parameter decode | mitigate | try/catch around Buffer.from + JSON.parse; any decode error returns 400 problem+json (never 500 or SQL error) |
| T-03-06b | Tampering | SQL injection via cursor values | mitigate | Decoded cursor values (created_at date, id string) passed via Drizzle sql template parameterization — never interpolated |
| T-03-06c | Tampering | limit parameter > 200 | mitigate | TypeBox GetPostingsQuerySchema has maximum:200 on limit field; Ajv rejects before handler; belt-and-suspenders Math.min in handler |
| T-03-06d | Tampering | accounts INSERT with invalid type | mitigate | TypeBox enum validation (5 literal types) rejects invalid type strings before handler |
| T-03-06e | Information Disclosure | account_balance.balance in response | accept | balance is a numeric value (no PII); amounts are already a core API concept; caller has full read access |
| T-03-06f | Information Disclosure | metadata JSONB stored and returned | mitigate | owner_ref and metadata are caller-supplied; pino logging never logs response bodies (D-10); metadata is returned as-is — callers must not store PII here (documented in API spec) |
</threat_model>
