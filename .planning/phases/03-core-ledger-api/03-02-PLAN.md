<objective>
Add postings.created_at column via migration 0010, apply it to the local Postgres container, and update schema.ts. This column is the sort key for cursor pagination in GET /v1/accounts/:id/postings (per D-04).

Purpose: UUIDv4 IDs are random and cannot serve as cursor pagination keys (Pitfall 5 in RESEARCH.md). The created_at column is the only semantically meaningful sort key.
Output: Migration 0010 SQL file, updated _journal.json, updated schema.ts, migration applied to local DB.
</objective>
