<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process.env → postgres connection string | DATABASE_URL is an environment variable; must not be logged |
| GET /health → response body | 503 response must not expose internal error details |
| SIGTERM → process.exit | Graceful shutdown must close DB connections before exit |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07a | Information Disclosure | GET /health 503 response | mitigate | health.ts 503 handler returns 'unreachable' not err.message; confirmed by test and grep assertion |
| T-03-07b | Information Disclosure | main.ts startup logs | mitigate | pino logger with redact configured in createServer; DATABASE_URL never logged (only port logged at startup) |
| T-03-07c | Denial of Service | missing SIGTERM handler | mitigate | process.on('SIGTERM') closes app + pgClient before exit; prevents connection leaks in containerized deployment |
| T-03-07d | Information Disclosure | DATABASE_URL in env | accept | env vars are standard practice; secret management is infrastructure concern; no DATABASE_URL logged in application code |
| T-03-07e | Information Disclosure | OpenAPI spec at /docs | accept | No auth in v0.1 (deferred); spec contains schema documentation only, no secrets; acceptable for OSS self-hosted deployment |
</threat_model>
