<!-- Health route contract -->
GET /health:
  No auth, no params, no body
  200: { status: 'ok', postgres: 'up' }
  503: { status: 'error', postgres: string }  ← string contains error description (not PG internals)

Health check implementation:
  await db.execute(sql`SELECT 1`)  ← if throws → 503
  Catch block: catch (err) { reply.status(503).send({ status: 'error', postgres: 'unreachable' }) }
  Do NOT expose err.message in the response (PII/internals risk)

OpenAPI validation targets:
  - GET /docs returns 200 (Swagger UI HTML)
  - GET /docs/json returns 200 (OpenAPI spec JSON)
  - spec.paths['/v1/transactions'] exists with POST

  - spec.paths['/v1/accounts'] exists with POST
  - spec.paths['/v1/accounts/{id}'] exists with GET
  - spec.paths['/v1/accounts/{id}/postings'] exists with GET
  - spec.paths['/health'] exists with GET
  - In POST /v1/transactions response schema: amount_cents has type: 'string' (not 'integer' or 'number')

Coverage gate:
  pnpm --filter @aprumo/core test --coverage
  Expect: @aprumo/core LoC coverage ≥ 90% (CI gate)
