    - Balanced postings + valid Idempotency-Key → 201, body: TransactionResponseSchema, amount_cents in each posting is a JSON string not number
    - Same Idempotency-Key sent sequentially (2nd call) → 200, body identical to first response
    - Same Idempotency-Key sent concurrently via Promise.all(2 requests) → both resolve 200 (or one 201 + one 200), both bodies have identical transaction id
    - Unbalanced postings → 422, body: { code: 'unbalanced_postings', status: 422 }, Content-Type: application/problem+json

    GET /v1/transactions/:id:
    - Valid uuid that exists → 200 with transaction + postings array ordered (include created_at in postings)
    - UUID not found → 404, body: { code: 'not_found', status: 404 }
    - Invalid UUID format → 400 (Fastify schema validation rejects non-uuid format string)
  </behavior>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP POST body → post_transaction SQL | amount_cents and account_id from client must be parameterized in SQL |
| Idempotency-Key header → transactions.idempotency_key | Key is user-supplied; length-bounded by TypeBox schema |
| BigInt → JSON response | setSerializerCompiler must fire before native JSON.stringify sees bigint |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05a | Tampering | SQL injection via postings body | mitigate | All scalars in post_transaction call use Drizzle sql template parameterization ($N placeholders); never string interpolation for user values |
| T-03-05b | Tampering | amount_cents negative or zero | mitigate | TypeBox PostingInputSchema has minimum:1 on amount_cents (Type.Integer({minimum:1})); Ajv rejects ≤0 before handler runs |
| T-03-05c | Tampering | amount_cents non-integer (float) | mitigate | TypeBox Type.Integer() rejects 1.5, "100", null etc. before handler; coerceTypes:false prevents silent coercion |
| T-03-05d | Tampering | account_id not a UUID | mitigate | TypeBox format:'uuid' validation on account_id in PostingInputSchema; Ajv rejects non-UUID strings |
| T-03-05e | Tampering | Idempotency-Key replay by different caller | accept | No auth in v0.1 (deferred per CONTEXT.md); idempotency key is not a secret, it prevents accidental duplicates not malicious replay |
| T-03-05f | Information Disclosure | 500 error responses | mitigate | pgErrorHandler 500 path returns generic detail — asserted in Plan 03-03 tests |
</threat_model>
